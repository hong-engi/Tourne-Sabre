# 적과 부위의 실제 표시 크기 제작 기록

일반 적은 긴 변 46칸, 정예는 56칸, 부위는 34칸의 색 덩어리로 정리한다. 바깥 여백을 포함한 PNG는 각각 약 50px, 60px, 38px이다. 일반 적과 정예는 최대 12색, 부위는 최대 10색으로 양자화한 뒤 남색 외곽선을 더한다. 원본 명암과 눈·갈라진 표면·금속 테두리 같은 식별점을 남긴다. 충돌 반경은 기존 값을 사용한다.

원본은 `*-source.png`, 변환본은 `*-fixer.png`, 국소 수정 전 파일은 `*-quantized.png`다. `edits.json`은 양자화 격자 좌표에서 직접 정리한 위치와 결과 RGBA를 기록한다. `existing-cleanup.json`은 기존 네 종에서 남색으로 교체한 외곽 픽셀과 원래 색을 기록한다. 코드 마스크 네 종은 `export_masks.py`로 원래 격자에서 PNG로 옮긴다.

재현은 이 디렉터리의 `prepare.py /private/tmp/tourne-pixel-fixer-eval/python <batch>`를 사용한다. `--finish`를 붙이면 보존한 Fixer 결과부터 다시 처리할 수 있다. Fixer 체크아웃은 `ef376e57e1c272633ca2dbf5f29ec3fcf6596465`이며, `mode=full`의 격자 크기는 알파로 자른 원본의 긴 변을 목표 격자 수로 나눈 값이다. 처음 생성한 일반·정예 프롬프트는 앞선 배치 디렉터리 또는 이 디렉터리의 개별 프롬프트 파일에 보관한다.

가면 미끼꾼의 원본은 8개 자세가 있는 아틀라스였다. 첫 칸 `(0, 0, 460, 535)`만 원본 해상도에서 잘라 Fixer에 전달했다. 최종 이미지는 본체와 분신이 공유한다. `thief`는 요청된 PNG를 연결했으며 현재 적 목록에서는 제외된 상태다. 기존 검성과 소라게는 Enemy Lab에서 확인했고 기존 파일을 보존했다.

`preview.png`에 전체 45종을 모았다. PNG 검사에서 16색 이하·이진 알파·최소 1px 여백을 확인했다. Enemy Lab에서는 수정한 가면과 분신, 사슬 간수와 말뚝, 풍선과 본체, 이동 중 지네왕과 마디를 확인했다. 최종 프런트엔드 테스트 62개, 백엔드 테스트 80개, 프로덕션 빌드가 통과했다.
