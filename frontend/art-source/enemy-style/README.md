# 적 스프라이트 스타일 보정

가면 미끼꾼과 균열 버섯의 뚜렷한 윤곽과 큰 명암 덩어리를 기준으로 삼았다. 기존 코드 마스크에서 만든 네 PNG는 원래 눈·심지·균열을 보존하고, 더 촘촘한 격자에서 외곽 모서리와 몸통 명암을 보정했다. 방패 등딱지·유리 산탄충·재조립 해골은 가까운 색을 묶고 고립된 내부 장식 픽셀을 줄였다. 연금술사는 몸 바깥의 녹색 밝기를 낮췄다.

`*-before.png`는 보정 전 게임 파일이다. 이미 픽셀 격자가 있는 파일을 직접 보정했으며, `python3 frontend/art-source/enemy-style/refine.py`로 재현한다. `final.json`에 최종 크기와 색상 수를 기록했다. `comparison.png`는 위가 수정 전, 아래가 수정 후다.
